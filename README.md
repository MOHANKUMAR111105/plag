# Plagiarism Checker

A web-based plagiarism checker built using Python and Flask.

## Features
- Check plagiarism from text input
- Upload files for plagiarism checking
- Compare similarity between multiple files
- User-friendly web interface

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## Project Structure

```text

```

## How to Run

1. Install dependencies

```bash
pip install -r requirements.txt
```

2. Run the application

```bash
python app.py
```

3. Open your browser and visit:

```
http://127.0.0.1:5000
```
